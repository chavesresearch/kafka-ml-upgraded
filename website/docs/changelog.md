# Changelog

- **29/04/2021** — Integration of distributed models.
- **05/11/2021** — Automation of data types and reshapes for the training module.
- **20/01/2022** — Added GPU support. ML code moved out of the backend.
- **04/03/2022** — Added PyTorch ML framework support.
- **08/04/2022** — Learning-curve visualization, confusion matrix generation,
  and metrics-visualization improvements. Datasets can now be split into
  training, validation, and test.
- **26/05/2022** — Prediction-data visualization: train, deploy for
  inference, and visualize predictions from data streams alone.
- **14/07/2022** — Incremental training support, plus configuration of
  training parameters for distributed-model deployments.
- **02/09/2022** — Real-time display of training parameters.
- **26/12/2022** — Indefinite incremental training support.
- **07/07/2023** — Federated training support (TensorFlow/Keras only).
- **28/09/2023** — Federated learning extended to distributed neural
  networks and incremental training.
- **05/07/2024** — Semi-supervised learning support.
- **2026** — Full modernization pass: Litestar backend, React frontend,
  updated TensorFlow/PyTorch/Kubernetes dependencies throughout, and a
  local Ethereum devnet enabling real end-to-end verification of
  blockchain-traced federated learning (CASE 9) for the first time.
